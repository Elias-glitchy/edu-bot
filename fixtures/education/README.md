# Fictional education demo data

Every record in this folder is fabricated for BUILD BOT 2.0 testing. Upload `rubric.json` as **Rubric**, `demo_gradebook.csv` as **Fictional roster**, and the files in `assignments/` as **Assignments**. Enable the controlled QA injection in the mission form to demonstrate a real detected-and-corrected total mismatch.

Generated scores and feedback are drafts requiring qualified educator review. Do not replace these fixtures with real student information in this local hackathon build.
