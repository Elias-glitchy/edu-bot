# BUILD BOT generated robot portrait library

Target: 200 original full-colour square portrait-profile robots.

Generation mode: OpenAI built-in image generation, one generation per character. The supplied blue BUILD BOT robot was used only as a high-level quality and visual-language reference. Every generated character must vary in silhouette, facial display, sensor layout, proportions, materials, and palette—not merely colour.

## Shared production prompt

- Use case: `stylized-concept`
- Asset: square portrait profile avatar for BUILD BOT
- Style: premium polished 3D character render, full colour, cinematic studio quality
- Framing: centered head and shoulders, complete head and upper torso, safe margin for circular avatar cropping
- Background: clean near-black studio vignette
- Required: one friendly original robot, distinctive silhouette and facial display
- Exclude: text, numbers, logos, watermark, weapons, extra characters, cropped head/shoulders, monochrome treatment, or a white-and-blue clone of the reference
