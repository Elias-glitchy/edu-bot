# BUILD BOT — MISSIONS & ROUTINES PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Missions & Routines** page using the master design system.

Create an autonomous work-planning dashboard for daily, weekly and recurring objectives.

Include a Create Mission action, upcoming missions, active missions, completed missions and reusable routines.

Support the signature BUILD BOT workflow: the user assigns goals on Sunday, CHIEF creates a plan, and managers execute from Monday through Saturday.

A mission detail view must show:
- Mission objective
- Start and end date
- Assigned manager and agents
- Measurable goals and progress
- Dependencies and subtasks
- Current execution state
- Approval requirements
- Recent verified activity
- Scheduled reports
- Blockers and recovery options

Include timeline and list views, plus Edit, Pause, Resume, Cancel and Duplicate Mission.

Support automations triggered by schedule or permitted events.

Allow users to teach reusable workflows through demonstrated actions where supported, with a review and test process before activation.

Design empty, planning, active, blocked, completed and failed states.

Deliver light and dark desktop/mobile layouts.
