# BUILD BOT — REPORTS PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Executive Reports** page using the master design system.

Create a premium reporting center where CHIEF consolidates information from all AI Managers and custom bots.

The user receives scheduled morning, afternoon and evening briefings and a weekly performance review.

Create tabs for Daily Briefings, Weekly Reports, Mission Performance and Manager Reports.

Each report should show:
- Reporting period
- Objectives versus actual verified results
- Completed work
- Work in progress
- Pending approvals
- Blockers and failures
- Revenue and pipeline metrics where connected data exists
- Recommendations for improving business performance
- Next planned actions
- Links to underlying activity and evidence

Use restrained monochrome charts, clear KPI summaries and intelligently written narratives.

Support text reading and voice playback in compatible environments.

Include date filters, share/export actions and notification preferences.

Show clearly when a metric is unavailable or estimated; never invent business performance.

Create light and dark desktop/mobile designs with empty, loading and report-ready states.
