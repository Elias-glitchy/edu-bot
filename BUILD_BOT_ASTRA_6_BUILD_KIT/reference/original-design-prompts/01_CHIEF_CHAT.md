# BUILD BOT — CHIEF CHAT PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Chief Chat** page using the master design system.

This is the user's main conversational command center. CHIEF is the AI Chief Executive who plans, delegates, coordinates other managers and reports back to the user.

Create a spacious, messaging-inspired interface with a collapsible left navigation, conversation history, CHIEF identity/avatar and a central chat thread.

Include a refined message composer with attachments, microphone, send button, tool access and optional voice conversation.

Show contextual interactive chat widgets for weekly mission proposals, delegated tasks, approvals, executive briefings and progress updates.

Add subtle activity indicators that show whether CHIEF is thinking, delegating, waiting for approval or reporting.

Allow the user to open live activity, review the execution plan, inspect delegated managers and interrupt or redirect ongoing work.

On first signup, show a genuine empty conversation with an inviting prompt such as: "What would you like your AI team to accomplish?"

Create light and dark desktop/mobile designs. Avoid turning the chat into an overcrowded analytics dashboard.
