# BUILD BOT — Stage 1 UX/UI Prompt Pack

This pack contains **one master design system** and **eleven page-specific design prompts** for BUILD BOT, a standalone subscription-based autonomous AI workforce platform.

## How to use in ChatGPT
1. Upload the ZIP to a new ChatGPT conversation.
2. Ask ChatGPT to **extract and read every Markdown file**, beginning with `00_MASTER_DESIGN_SYSTEM.md`.
3. Ask it to produce each page in numbered order. Every page needs desktop and mobile, in light and dark themes.
4. Keep the master design system active across every page to ensure visual consistency.
5. Review and approve a page before moving to the next one.

## Suggested prompt after upload
"Read all Markdown files in this ZIP. Treat `00_MASTER_DESIGN_SYSTEM.md` as the global design source of truth. Start with `01_CHIEF_CHAT.md`. Create a premium, coherent BUILD BOT application design in both fully white light mode and true-black dark mode, with desktop and mobile variants. Follow the requirements precisely, including empty/loading/error states. Do not skip screens, invent live business results, or redesign the brand. Continue through the pages in numbered order as I approve them."
