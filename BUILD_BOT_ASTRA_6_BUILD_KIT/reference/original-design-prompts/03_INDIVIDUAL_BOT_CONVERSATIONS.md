# BUILD BOT — INDIVIDUAL BOT CONVERSATIONS PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Individual Bot Conversation** page using the master design system.

Create a dedicated messaging interface for any built-in Manager or user-created bot.

The top header must show the bot avatar, name, specialty, activity status and actions for View Computer, Tasks, Memory and Configure.

Use natural conversational threads with file attachments, voice notes and structured cards for deliverables, research findings, action requests, completed tasks and relevant business records.

Provide a collapsible contextual right panel showing current mission, delegated tasks, recent activity and connected tools.

Show activity transitions such as Working, Awaiting Approval, Completed and Failed.

Include Pause, Resume and Stop controls when the bot is executing a task.

Users must be able to communicate directly with the manager without always going through CHIEF.

Create versions for a new empty conversation, an active execution session and an approval-blocked session.

Deliver light and dark desktop/mobile designs.
