# BUILD BOT — APPROVALS PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Approvals** page using the master design system.

Create a secure and clear approval inbox for actions that an AI bot has prepared but is not yet authorized to execute.

Include Pending, Approved, Rejected, Expired and All tabs.

Each approval request should display:
- Requesting bot
- Mission or related task
- Exact proposed action
- Relevant recipient or destination
- Financial value where applicable
- Content or document preview
- Risks and policy checks
- Request time and expiration
- Approve, Reject and Request Changes actions

Support configurable approval gates for external outreach, binding quotations, tender submissions, purchases, payments and business-critical record deletion.

Show policy modes: Always Ask, Autonomous Within Limits and Autonomous When Authorized.

Use confirmation for higher-impact actions, respect actual user permissions and never allow a user setting to override external legal or payment-provider authorization requirements.

Make approval decisions scoped to the reviewed action; materially changed actions must be approved again.

Provide detailed audit history.

When an action is waiting for approval, visually explain that the affected task is paused while unrelated authorized tasks can continue.

Deliver light and dark desktop/mobile layouts.
