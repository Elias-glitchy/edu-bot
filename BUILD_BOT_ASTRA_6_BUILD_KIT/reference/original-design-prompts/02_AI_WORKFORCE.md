# BUILD BOT — AI WORKFORCE PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **AI Workforce** page using the master design system.

Display CHIEF prominently at the top, followed by the ten built-in AI Managers and a separate section for user-created custom bots.

Use premium cards or a clean list/grid with recognizable avatars, bot names, roles, current activity states, last activity and concise task descriptions.

Include search, filters by status and role, and a prominent Create Bot action.

Clicking a bot should open its profile, individual conversation, instructions, activity and authorized tools.

Distinguish built-in bots from custom bots without excessive badges.

Provide controls to configure, pause or disable bots according to the user's privileges.

New accounts should display built-in bots as available but not falsely show them performing live work.

Include a useful empty state for custom bots.

Create light and dark desktop/mobile layouts, including hover previews and compact responsive cards.
