# BUILD BOT — ACTIVITY PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Activity** page using the master design system.

Create a chronological, searchable activity center that shows verified work performed by CHIEF, Managers and custom bots.

Provide filters by bot, mission, date, application, status and action type.

Each event should display the responsible bot, timestamp, action, result, target application and supporting evidence or artifact where applicable.

Use clear distinctions between:
- Planned
- In progress
- Completed
- Awaiting approval
- Failed
- Retried
- Cancelled

Allow users to expand an event to inspect logs, screenshots, tool outcomes, related CRM records or files, and previous recovery attempts.

Add a way to navigate from an event directly to the relevant bot conversation or cloud-computer session.

Include an activity timeline, useful summary metrics and exportable reports, but avoid fake real-time charts.

Provide empty states, error states, pagination and accessible filtering.

Deliver light and dark desktop/mobile designs.
