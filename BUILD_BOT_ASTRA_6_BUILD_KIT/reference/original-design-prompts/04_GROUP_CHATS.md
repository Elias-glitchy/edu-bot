# BUILD BOT — GROUP CHATS PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Group Conversations** page using the master design system.

Create a consumer-friendly group messaging interface allowing a human user, CHIEF, multiple AI Managers and selected custom bots to collaborate.

Include group name, participant avatars, participant management, group settings, shared files and mission context.

Show visually distinct messages from the human, CHIEF and each bot, with small readable avatars and names.

Display structured handoff cards such as:
- Intelligence Manager sends qualified prospects to Sales Manager.
- Sales Manager requests commercial review from Finance Manager.
- Outbound Manager receives an authorized outreach task.
- CHIEF summarizes decisions and assigns next steps.

Include a task handoff timeline and consolidated group summary accessible without cluttering the message thread.

Bots should communicate when a task requires collaboration, not generate endless autonomous conversations.

Provide options to mention a specific bot, ask the entire group, create a task and approve delegated work.

Design empty, active and completed group-session states in light and dark desktop/mobile layouts.
