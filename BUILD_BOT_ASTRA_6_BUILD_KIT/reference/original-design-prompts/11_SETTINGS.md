# BUILD BOT — SETTINGS PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Settings** page using the master design system.

Create a refined enterprise settings experience with a secondary navigation sidebar or section tabs.

Include these areas:

General: organization name, timezone, language and regional preferences.

Appearance: Light, Dark and System theme options with live previews. Both themes must apply to every page.

Profile & Team: personal profile, workspace members, invitation management and user roles.

AI Workforce Defaults: default CHIEF behavior, global mission policies, agent memory controls and reporting preferences.

Permissions & Approvals: delegated tool access, sensitive-action approval rules, spending limits, communication limits and audit history.

Connections: BUILD Growth, email, calendar, CRM, business applications and supported external tools.

Cloud Computers: session policies, workspace isolation, authorized takeover and resource limits.

Voice & Notifications: voice settings, morning/afternoon/evening briefing schedules, notifications and preferred delivery channels.

Billing & Subscription: current subscription, usage allowances, invoices, payment method, renewal and optional additional usage.

Security & Privacy: authentication, active sessions, credential management, data retention, export and account deletion.

Use an uncluttered layout with clear save states, confirmation dialogs and permission descriptions.

Include account and organization separation where appropriate.

Deliver light and dark desktop/mobile designs.
