# BUILD BOT — CLOUD COMPUTER VIEWER PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Cloud Computer Viewer** page using the master design system.

This interface allows authorized users to observe a bot's real cloud execution environment.

Create a premium workspace viewer with a live desktop/browser viewing area, selected bot identity, active task, session status and elapsed execution time.

Include View Only, Pause, Resume, Take Control, Return Control and Stop Session actions, with appropriate confirmation and permission requirements.

Use a collapsible side panel for:
- Current task and execution plan
- Completed steps
- Recent tool calls
- Files and artifacts
- Screenshots and activity evidence
- Errors and recovery attempts
- Pending approvals

Provide fullscreen viewing and convenient navigation back to the associated bot conversation.

Display realistic session states: starting, connecting, running, awaiting approval, paused, disconnected and finished.

Distinguish the bot's browser actions from first-party BUILD BOT or integrated application API actions. Do not falsely render API-only operations as browser activity.

Do not expose secrets or sensitive credentials in shared previews.

Deliver light and dark desktop/mobile designs, with appropriate mobile viewing controls.
