# BUILD BOT — BOT CONFIGURATION PAGE PROMPT

**Instruction:** Apply `00_MASTER_DESIGN_SYSTEM.md` to this page.

Design BUILD BOT's **Bot Creation & Configuration** page using the master design system.

Create a no-code configuration experience allowing customers to build their own persistent AI bots.

Use a simple step-by-step creation flow and a full bot configuration screen after creation.

Include:
1. Bot identity: name, avatar, description and purpose.
2. Role and instructions: objectives, responsibilities, operating rules and communication style.
3. Knowledge: user-uploaded files, approved sources and scoped persistent memory.
4. Tools: authorized integrations, BUILD Growth modules, connected apps and browser/computer capabilities.
5. Autonomy: allowed actions, limits and approval requirements.
6. Missions: recurring tasks, schedules and triggers.
7. Collaboration: report to CHIEF, operate independently or work with selected managers.
8. Reporting: progress notifications, summary frequency and escalation rules.
9. Testing: sandbox trial, tool-access check and permission validation.
10. Deployment: review settings and activate the bot.

Allow built-in Managers to be customized within safe boundaries without modifying protected system instructions.

Include configuration version history, duplicate bot, pause, archive and delete options.

Show permission scope clearly and warn users when they grant powerful capabilities.

Provide separate create, edit, test and deploy states.

Deliver light and dark desktop/mobile designs.
